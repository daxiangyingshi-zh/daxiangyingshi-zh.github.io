观片手记

Viewing Notes
NOTE 01 / 选片

先定介质，再定片单

同一部片子在影院、电视与笔记本上的信息量并不相等。动手列单前，先写清观看条件。

  1. 记下屏幕比例与音响环境
  2. 区分「首刷」与「重看」两套清单
  3. 给每部片子标一个观看动机，不超过六个字
NOTE 02 / 读帧

黑场不是空白

切光、静帧、环境声，往往藏着导演的真正落点。这几条比剧情更值得回放。

  1. 开场三分钟内出现的物件，多半会回来
  2. 注意群演的动线，而非主角的台词
  3. 字幕结束后多留三十秒，别急着退出
NOTE 03 / 归档

让笔记能再查一次

观后感写得太满反而找不到。固定四个字段，半年后仍能检索。

  1. 片名 + 年份 + 版本
  2. 一个关键词（不是形容词）
  3. 时间戳：分秒位置
  4. 待证疑问，留给下次重看

术语索引

Index of Terms
长镜头
不靠剪辑、而靠机位运动与场面调度推进的一段连续影像。衡量标准是「时间是否被保留」。
画幅比
1.33:1、1.85:1、2.39:1 不是装饰参数，它决定观众把注意力放在人脸还是空间。
场记板
标注场次、镜次与拍摄日期的小黑板，后期对位声画的起点。 参见：剪辑对位
修复版
对褪色、划痕与声轨噪点做校正后的母版，不等于重新调色，也不必然更接近首映时的观感。
环境声
画面里没有明确来源的背景声响，负责让场景「站得住」。静音反而是一种刻意的选择。
分镜
把剧本拆成镜头动作的草图，是剪辑节奏的预演，常被误当作纯美术稿。
同期声
拍摄现场同步收录的人声与环境声，与后期配音在质感上有细微但可辨的差别。
片尾字幕
不仅是署名清单，也是声音设计与余韵的延续段落，很多作品的结尾其实从这里才开始。
